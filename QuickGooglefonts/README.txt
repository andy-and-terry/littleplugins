In this file, you will learn how to use the
HTML/JS-compactible QuickGoogleFonts plugin [2026]
-----------------------------------------------
1. Setup
To setup this plugin, you will need to import
the JS file into your HTML document.
[RECOMMENDED]:
<script defer src=""></script
-----------------------------------------------
2. Usage
To use this, you have to use the following JS
function(s).

//choose font by ID
setFontID(id)
//choose font by name
setFontNAME(name)
//default font (Sans Serif)
setFontDEFAULT()
